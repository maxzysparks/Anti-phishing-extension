================================================================================
FEATURE DETAILS
================================================================================

TensorFlow.js Manager:
- initialize(): Sets up TensorFlow backend
- createPhishingModel(): Creates neural network
- predict(urlAnalysis): Returns threat probabilities
- trainWithFeedback(data): Trains model on user feedback
- saveModel()/loadModel(): Persists model to IndexedDB

NLP Analyzer:
- analyzeEmailContent(text, subject): Analyzes email for phishing
- heuristicAnalysis(text): Detects suspicious patterns
- semanticAnalysis(text): Uses sentence embeddings
- analyzeSender(email, name, domain): Validates sender

Behavioral Learning:
- recordFeedback(url, threat, action): Records user action
- trainModel(): Trains TF model with accumulated feedback
- getLearningStats(): Returns training statistics
- getPersonalizedRecommendations(): Provides user-specific tips

Visual Similarity:
- initialize(): Sets up canvas and loads brand signatures
- analyzeImage(img): Extracts features and compares to brands
- scanPageImages(document): Scans all images on page
- findSimilarLogos(features): Matches against known brands
