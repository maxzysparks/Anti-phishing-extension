```javascript
  ttl: 3

```

### Anonymization Process:

**URL Anonymization:**
- Hash full domain
- Keep TLD only
- Extract patterns (IP, subdomains, path length)
- No actual URLs shared

**Content Anonymization:**
- Pattern detection only (urgency, login, financial)
- Length rounded to nearest 100
- No actual content shared

**Technique Anonymization:**
- Share technique names only
- No implementation details

### Usage Example:

```javascript
import { p2pThreatNetwork } from './network/p2p-threat-network.js';

// Initialize
await p2pThreatNetwork.initialize();

// Share threat
await p2pThreatNetwork.shareThreat({
  url: 'https://phishing-site.com',
  content: 'Urgent! Verify your account',
  type: 'phishing',
  severity: 'high',
  confidence: 0.9
});

// Query network threats
const threats = await p2pThreatNetwork.queryThreats({
  timeWindow: 3600000, // Last hour
  minSeverity: 'high'
});

// Get threat count
const count = await p2pThreatNetwork.getNetworkThreatCount();

// Get statistics
const stats = p2pThreatNetwork.getStatistics();
```
